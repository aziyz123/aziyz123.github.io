📲 Ilova / yorliq o'rnatish

Qurilmangizga qarab birini tanlang.

🤖 Android uchun APK yuklab olish
Yorliq (.url) qanday ishlatiladi: yuklangan faylni Ish stoliga ko'chiring. Ustiga ikki marta bossangiz, sayt brauzerda ochiladi.

Chrome (Windows doskasi): o'ng yuqoridagi ⋮ → «Quyish, saqlash va ulashish» → «Sahifani ilova sifatida o'rnatish» yoki «Yorliq yaratish» («Ochilsin: alohida oynada» belgilang).
Microsoft Edge: ⋯ → «Ilovalar» → «Ushbu saytni ilova sifatida o'rnatish».
Android doska: Chrome ⋮ → «Bosh ekranga qo'shish», yoki yuqoridagi APK.

Menyuda bunday band yo'q bo'lsa, brauzer eski bo'lishi mumkin. Chrome yoki Edge'ni yangilang. O'rnatilmasa ham, yorliq (.url) har doim ishlaydi.
